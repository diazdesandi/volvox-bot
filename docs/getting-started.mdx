# Getting started

<Callout type="info">
No installation required. No hosting. No configuration files. Volvox.Bot handles everything.
</Callout>

<Steps>

## Add Volvox.Bot to your server

Go to [volvox.bot](https://volvox.bot) and select **Add to Server**. The landing-page button starts the Discord invite flow, lets you select a server, and returns you to the dashboard after approval.

The bot requests only the permissions it needs. Review them and approve.

<Callout type="tip">
You need **Manage Server** permission in the target Discord server to add bots.
</Callout>

## Open the dashboard

The Add to Server flow returns you to the dashboard automatically. If you come back later, go to [volvox.bot](https://volvox.bot), select **Login with Discord**, and authorize the OAuth2 connection.

Once logged in, the dashboard opens a server picker when Volvox.Bot isn't yet installed in one of your manageable servers. Server cards show **Manage** when the bot is already present and **Add Bot** when it still needs to be invited.

The dashboard **Add Bot** flow returns you to the server picker after Discord approval. Use **Refresh server list** if Discord hasn't caught up after an invite.

## Configure your server

Open **Config** in the dashboard sidebar. Here you can:

- Toggle features on and off
- Set moderation rules and thresholds
- Configure AI conversation settings
- Set up ticket categories
- Customize community features

<Callout type="tip">
All changes apply instantly — no restarts needed.
</Callout>

## That's it

Your bot is live. Explore the dashboard to see analytics, manage moderation, set up tickets, and more.

</Steps>
