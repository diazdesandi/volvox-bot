# Getting started

<Callout type="info">
No installation required. No hosting. No configuration files. Volvox.Bot handles everything.
</Callout>

<Steps>

## Add Volvox.Bot to your server

Go to [volvox.bot](https://volvox.bot) and select **Add to Server**. The landing-page button opens Discord's bot invite in a new tab so you can select a server and approve the requested permissions.

Alternatively, you can use this direct Discord invite link:

[Add Volvox.Bot to Discord](https://discord.com/oauth2/authorize?client_id=1467236664853139477&permissions=1099511704598&scope=bot%20applications.commands)

The bot requests only the permissions it needs. Review them and approve.

<Callout type="tip">
You need **Manage Server** permission in the target Discord server to add bots.
</Callout>

## Open the dashboard

Go to [volvox.bot](https://volvox.bot) and select **Login with Discord**. Authorize the OAuth2 connection.

Once logged in, the dashboard opens a server picker when Volvox.Bot is not installed in one of your manageable servers yet. Server cards show **Manage** when the bot is already present and **Add Bot** when it still needs to be invited.

The dashboard **Add Bot** flow returns you to the server picker after Discord approval. Use **Refresh server list** if Discord has not caught up after an invite.

## Configure your server

Open **Config** in the dashboard sidebar. Here you can:

- Toggle features on and off
- Set moderation rules and thresholds
- Configure AI conversation settings
- Set up ticket categories
- Customize community features

<Callout type="tip">
All changes apply instantly — no restarts needed.
</Callout>

## That's it

Your bot is live. Explore the dashboard to see analytics, manage moderation, set up tickets, and more.

</Steps>
