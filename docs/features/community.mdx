# Community

Community features help your server members engage and show off their activity. Leaderboards, XP, and member showcases are on by default — you can toggle every feature from the dashboard.

## What it does

- **Leaderboards** — XP-based leaderboards (experience points earned through activity) visible in Discord and on the web
- **Showcases** — Highlight top members or content
- **Starboard** — Repost popular messages to a dedicated channel once reactions reach your threshold
- **Public profiles** — Give your members a web-accessible profile page
- **Community hubs** — Read-only public views of server stats and leaderboards

## How to use

1. Members earn XP through activity (messages, reactions, events) as soon as the bot joins
2. Leaderboards update automatically
3. View public profiles at `https://volvox.bot/community/{guildId}`
4. Open **Config → Community** to fine-tune XP rates, badges, or turn features off

## Starboard

Open **Config → Community Tools → Starboard**, enable the feature, select a destination channel, set the reaction threshold, and select either a specific emoji or **Any**.

React to messages in a normal source channel, not in the starboard destination channel. The bot ignores messages posted in the destination channel, so it doesn't repost its own starboard entries.

The bot creates starboard posts from reaction events. It doesn't backfill existing messages that already met the threshold before you enabled starboard or changed the threshold. To trigger the first post, remove and re-add one qualifying reaction, or add another qualifying reaction.

<Callout type="tip">
Community Hubs let non-members see your server's public face — great for recruitment.
</Callout>

## Hubs in the dashboard server selector

When you enable Community Hubs for a server, every member sees it in their dashboard server selector under **Community Hubs**. No moderation or admin access required. Selecting a hub opens the read-only public view at `/community/{guildId}`.

Servers without Community Hubs enabled stay hidden from members who lack management permissions. The selector only surfaces hubs you've intentionally made public. If you have admin or moderator access, you still see every managed server in the **Workspaces** section (your managed servers) above the hubs list.

## Configuration

| Setting | Description | Default |
|---------|-------------|---------|
| Engagement tracking | Track messages and reactions for XP and badges | On |
| Reputation (XP) | Award XP per message, reaction, and event | On |
| Starboard | Repost messages once reactions meet the configured threshold | Off |
| Leaderboard visibility | Public or members-only | Public |
| XP system | Configure how members earn XP | Built-in defaults |
| Showcases | Which stats to highlight | Top members |
| Public profiles | Allow members to have public pages | On |
